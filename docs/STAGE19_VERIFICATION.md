## 상태·현재 의도·집행 경계

- idle/준비·조회 중(loading)/준비됨·미실행(prepared)/전송 중(executing)/서버 접수·처리 중(pending)을 구분합니다. ACK를 실제 효과로 표시하지 않습니다.
- succeeded에서도 effectApplied:true와 유효한 관측 시각·현재 접수 기록이 없으면 unknown으로 표시합니다. 성공 표시는 관측 시각·effectApplied:true·receiptId와 함께입니다.
- denied/failed/error/expired는 원래 코드와 안전한 이유를 표시합니다. unknown은 성공이나 효과 없음으로 단정하지 않으며 재집행 대신 결과만 직접 재조회하도록 안내합니다.
- 현재 event.id·근거ID·actionId·target.id/generation·receipt.requestId/receiptId/version을 받은 범위만 표시합니다. 다른 사건·조치의 receipt는 현재 결과로 붙이지 않습니다. 동적으로 event/request 속성을 붙이며 초기화에서는 이전 대상·요청·관측·속성이 남지 않습니다.
- 준비 상태에서 사람 확인 기한과 제공 확인 버튼 사용을 안내합니다. 학생 함수는 확인 티켓 필드를 읽거나 만들지 않으며 실행 버튼·POST·타이머·자동 재집행을 추가하지 않습니다. 재사용 응답(replayed)은 같은 요청의 기존 결과로 구분합니다.
- 조치 화면 취소가 이미 전달된 조치 효과를 되돌리는 기능이 아님을 표시합니다.
