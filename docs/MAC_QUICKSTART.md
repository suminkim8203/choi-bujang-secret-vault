# 켈비 Mac 사용 안내 — 2026-10-28

승인한 새 UI를 반영한 **기본 Mac 앱 0.1.1**을 사용할 수 있습니다. 현재 Apple Silicon Mac에서 검증했습니다. 설치 프로그램이 아니라 `.app`과 ZIP이며, 과제 제출은 하지 않았습니다.

## 앱으로 켜기

1. `Kelbi-Mac-arm64-basic-0.1.1.zip`을 풀고 안의 **켈비.app**을 엽니다. 외부 Node.js나 켜 둔 개발 서버는 필요하지 않습니다.
2. 이전 켈비 앱이 실행 중이면 먼저 그 앱을 종료한 뒤 새 앱을 엽니다. 같은 앱이 이미 실행돼 있으면 이전 창이 앞으로 올 수 있습니다. 이번 검증에서는 기존 앱을 닫지 않고 별도 임시 프로필로 새 앱을 시험했습니다.
3. 관리자 권한이나 Applications 폴더로의 이동은 필요하지 않습니다. OS가 실행을 막는 경우 보호 기능을 끄거나 경고를 우회하지 말고 메시지를 확인합니다.

## 써 보기

1. **보호 현황 → PC 상태 다시 조회**를 누릅니다. CPU·메모리·디스크 수치, 가로 막대와 마지막 조회 시각이 나타납니다.
2. 네 번 조회하면 **사용량의 변화** 그래프가 나타납니다. **최근 조회 기록**을 펼쳐 같은 수치가 표에 있는지 확인합니다. 자동 감시가 아니라 버튼을 누른 시점끼리 비교합니다.
3. **측정 상태와 제한**, **측정 근거와 제한**을 읽습니다. 디스크 막대는 사용률이 아니라 여유 비율입니다.
4. 상단 **업무 앱**, **보안 기록**으로 이동한 뒤 **보호 현황**으로 돌아옵니다. 메뉴는 좌·우 방향키와 Home/End로도 이동할 수 있습니다.
5. **이 탭의 조회 기록 지우기** 또는 **Command+R**로 현재 수치·그래프·기록이 초기화되는지 확인합니다.
6. 종료는 **켈비 → 켈비 종료** 또는 **Command+Q**입니다. 앱이 만든 로컬 서버도 함께 닫힙니다. 다시 열면 조회 전·기록0회부터 시작합니다.

상단 **다시 불러오기**는 보안 연결 정보를 다시 읽는 동작입니다. PC 비교 기록을 쌓으려면 **PC 상태 다시 조회**를 사용합니다.

## 수치와 연결 상태 읽기

- 회색 **보안 서버 · 연결 없음**은 이 묶음에 운영 보안 서버가 연결되지 않았다는 뜻입니다. PC 실측 성공과 보안 연결 성공을 혼동하지 않습니다.
- 조회 전·확인 불가·실제0%는 서로 다릅니다. 실패하면 현재 수치를 비우고 과거 그래프·기록을 과거 결과로만 남깁니다. 실행 상태를 확인한 뒤 직접 다시 조회합니다.
- Mac에서 Windows 방화벽·Windows 기록은 미지원입니다. CPU·메모리·디스크·네트워크 구성은 실제 로컬 읽기입니다.
- 수치와 편의 기준은 공격·감염·안전 판정이나 보안 점수가 아닙니다. Mac 메모리 압력·캐시·압축을 대신하는 값도 아닙니다.
- 최근20회는 현재 탭에만 남습니다. 영구 저장·자동 조회·외부 전송 기능을 추가하지 않았습니다.
- 보안 엔진·계정·AI·조치 집행의 운영 연결은 이 기본 앱의 검증 범위에 포함하지 않습니다. 비밀번호·키를 입력할 필요가 없습니다.

## 소스에서 실행하기 — 개발용 선택 경로

Node.js 22~24가 있는 Mac의 저장소 루트에서 다음을 실행합니다. 실제 검증한 개발 환경은 Node24.10.0/npm11.6.0이며, 수업 기준 Node24.19.0과 구분합니다. 기본 앱은 별도 내장 Node24.22.0을 사용합니다.

```sh
ON_PORT=5197 npm start --prefix on-client
```

http://127.0.0.1:5197/ 를 열고, 종료는 해당 실행 창의 Ctrl+C입니다. 이미 실행 중이면 다시 실행하지 않습니다. 포트 충돌 때문에 다른 서버를 종료하지 않습니다.

기본 앱은 고정 웹 주소를 사용하지 않고 자체 임시 포트를 엽니다. 개발 서버 주소와 혼동하지 않습니다. 앱은 현재 Mac에서 로컬 자체 서명을 검증했으며 Developer ID 서명·공증을 받은 외부 배포본은 아닙니다.
