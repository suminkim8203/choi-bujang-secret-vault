## 버전·인수인계·남은 항목

실행 소스는20단계 구현 뒤 변경하지 않았으며21·22단계는 학생 문서·증빙만 보완합니다. 현재 버전과 변경 이력은 [릴리스 기록](RELEASE_NOTES.md), 실행 절차는 [학생 설명서](STUDENT_RUNBOOK.md)에 있습니다. 새 폴더에도 전체 on-client와 공개 설정 견본·같은 검사·문서가 포함되고, 하드코딩한 개인 절대경로나 이전 폴더의 비밀에 의존하지 않습니다.

Windows 실제 실행·native 로그인·운영 SDP/AI 대응·실제 모델 설명·실제 원천 집행과 결과 관측·승인 패키지 OSV 조회는 기다림(UNV)입니다. 최종 단계의 코드/문서 판정이 통과해도 이 항목을 운영 인증·v1.0으로 바꾸지 않습니다. 서버의 AI는 제출 원문을 읽을 뿐 이 재현을 직접 실행하지 않으며, 이번 관찰은 위 환경에서 Codex가 수행한 증거입니다.
