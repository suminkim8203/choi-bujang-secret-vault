2026-10-23 20단계9항목 통과 직후21단계가 제출 가능으로 바뀐 것을 실제 확인했습니다. 이전의20단계 공개 상한 안내를 고정 사실로 사용하지 않습니다. 현재 공식 포털은 README·학생 문서·글 구성도·제공 코드/설정 견본을 함께 읽으며 서버가 실행하지 않는다고 명시합니다. 옛 제공 FINAL_PRODUCT_GUIDE의10월15일 미개방 설명보다 현재 운영 화면을 우선합니다.

## 변경 범위

새 [학생 실행 설명서](STUDENT_RUNBOOK.md)에 목적·기능, 실제 버전과 지원/미확인 환경, 폴더·명령·실행 위치·주소·시작 신호·종료·재실행, 파일 경로를 붙인 네 상자 Mermaid 구성도,8개 학생 함수/제공 코드 경계, 오류별 확인·복구, 기다림(UNV), 비밀·자료 보존을 정리했습니다. 제공 문서는 수정하지 않았고 앱57파일과 이전62검사는20단계 통과본 그대로입니다. Windows 공식 명령은 출처와 미실행을 명시하며 Mac 실제 실행과 혼동하지 않습니다.

## 문서 실행 검증

실제 환경은 macOS26.1/Node24.10.0/npm11.6.0입니다. 프로젝트 최상위의 새 zsh 터미널에서 `ON_PORT=5194 npm start --prefix on-client`를 실행해 `케셰브 연결 확인: http://127.0.0.1:5194` 메시지와 실제 브라우저의 연결 없음·세 메뉴를 확인했습니다. Ctrl+C로 종료한 뒤 같은 명령을 새 프로세스로 재실행하고 브라우저 새로고침 후 같은 기본 상태를 확인했습니다(15:59). Windows PowerShell·운영 계정·유료 AI·집행·실제 OSV 조회의 확인으로 기록하지 않습니다.

문서에 등장하는 실제 파일·스크립트·현재 package.json 명령과 상대 링크를 대조합니다. 앱은 외부 npm 의존성0이며 루트 자료실 의존성과 구분했습니다. 기동 신호와 연결 성공, 예제·단위 검사와 운영 성공, 공식 코드 판정과 실제 실행을 분리했습니다. 실제 계정·native·모델·조치·OSV 연결은 미확인 목록에 남깁니다.
