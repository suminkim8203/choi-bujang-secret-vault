## 변경·보존

시작 저장점은 `5abd4dd67af5ec56160f6615e06590914d40a13a`입니다. `on-client/student/extension.mjs`의 renderStatus를 구현하고, 공식 지시대로 renderEvents의 상세 안에 미지원 조치 안내만 더합니다. 13·14단계 함수와 15단계의 정렬·필터·상세 동작은 유지하며 17단계 이후 학생 함수, 제공 public/app.js·서버·인증·기존 방어전/XDR·DB 설정을 바꾸지 않습니다. 옛 제출 묶음과 루트 단계12 설정도 보존합니다.

## 재현·한계

macOS 저장소 루트에서 `ON_PORT=5190 npm run demo --prefix on-client` → http://127.0.0.1:5190/ 보호 현황 → 제공 진단 조회 → 학생 복사. 서버를 종료하고 직접 다시 불러오기/진단 조회 → 실패 확인 → 서버 재실행 → 같은 버튼을 직접 눌러 복구 확인합니다.

Node.js v24.10.0이며 공식 실행 안내22~24 범위 안입니다. 고정 검수24.19.0에서는 실행하지 않았습니다. 빈 목록·시간 초과·미지원 조치·민감 필드가 섞인 입력은 운영 설정을 바꾸지 않고 단위 검사로 확인했습니다. 실제 엔진·계정·AI 연결·조치는 미구성이며 예제 성공과 구분합니다. 학생 직접 실행 확인은 받지 않았고 브라우저 검증은 에이전트 수행입니다.

현재 포털은 17단계가10월26일 준비 중이며 이 반은16단계까지만 공개된다고 안내합니다. 16단계 판정 후 상태를 다시 확인하며, 단계 잠금을 우회하거나 운영 준비 전 AI 연결을 다른 방법으로 대체하지 않습니다.
