## 구현·검사

- idle/loading/error/ok를 분리하며 조회 중·실패·취소는 이전 표를 현재 결과로 표시하지 않습니다. 복구는 제공 설치 패키지 조회 버튼을 직접 누르도록 안내하며 학생 코드의 외부 호출·자동 재시도는0입니다.
- 전체 complete/partial/not_checked/not_configured/unverifiable을 한국어와 원래 코드로 표시합니다. lockfileVersion·lockfileHash·checkedAt은 전달된 경우에만 표시합니다. 없는 값을 만들지 않습니다.
- 각 패키지 행은 name과 정확한 설치 version에 대해 두 data-student-package 속성을 가지며 status/source/checkedAt을 표시합니다. 범위·태그를 실제 설치 버전으로 표시하지 않습니다.
- 취약점의 id·modified를 함께 표시합니다. 부분 실패(unverifiable)에 받은 ID가 있으면 일부 확인·전체 조회 확인 불가로 남기며, 다른 패키지에서 확인한 결과도 보존합니다.
- none_found는 그 조회 시각·범위에서 알려진 항목이 없다는 뜻이며 앱 전체 안전·침해 없음을 보장하지 않는다고 안내합니다. 미조회·실패·확인 불가는 이 결과와 구분합니다.
- 새 hash·버전·시각·목록으로 바뀌면 호출마다 새 DOM을 반환합니다. 제공 화면의 요청 세대 검사·취소·수동 다시 조회 경로는 변경하지 않았습니다.
