## 보존한 기능과 한계

- 제공된 PC 조회 API를 수동 호출합니다. CPU·메모리·디스크·네트워크 구성은 Mac에서 확인했고, Windows 방화벽·기록은 이 OS 미지원입니다.
- 최근 20회는 현재 탭 메모리에만 남습니다. 재실행·새로고침 뒤에도 보존되는 기록 기능은 구현하지 않았습니다.
- 과거 성공 수치를 새 조회의 성공으로 표시하지 않습니다. 보안 서버 연결 없음과 PC 수치 조회 성공은 별개입니다.
- 실제 보안 엔진·계정·AI·조치 집행의 운영 연결을 확인하지 않았습니다. 수업 통과를 운영 인증으로 표시하지 않습니다. 서비스 연결 없이 내 PC 기능 중심으로 진행할 수 있다는 제공 안내를 따릅니다.
- 제공 안내는 설치형 앱이 검증된 제공 화면을 쓴다고 설명합니다. 현재 `public/style.css`의 디자인이 설치형 화면에도 보인다고 가정하지 않으며, 새 UI 시스템 작업에서 설치형 반영 범위도 다시 확인해야 합니다.

## 이후 순서

1. UI와 무관한 기능·실행 재현 및 포장 사전 점검을 먼저 진행했습니다. 2026-10-27 새 사본 검증은 완료했고, 최종 포장은 실행하지 않았습니다. 현재 UI는 추가 수정하지 않습니다.
2. 새 UI 시스템에서 수정·적용할 때 같은 세 기능, 상태 구분, 기존 메뉴를 보존합니다.
3. 해당 UI에 맞춰 한 장 안내를 갱신하고 기능·키보드·좁은 화면을 다시 확인합니다.
4. 처음 쓰는 사람의 실제 따라 하기 결과와 막힌 부분을 기록하고 필요한 범위만 고칩니다.
5. 최종 코드·설명서의 저장점을 맞추고 담당자의 공식 포장 실행 환경과 설치형 화면 반영 범위를 확인합니다. 환경 준비는 학원 Windows에서 먼저 확인할 수 있습니다.
6. 같은 버전으로 포장·새 경로 설치·시연까지 검증합니다. 완료된 항목만 상태를 바꿉니다.
7. 제출은 계속 보류합니다. 명시적 제출 지시가 있을 때만 공식 접수 경로의 준비 상태를 확인하고 진행합니다.
