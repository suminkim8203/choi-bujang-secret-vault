# 켈비 18단계 · 근거에 연결된 AI 사건 설명

2026-10-23 현재 공식 포털에서17단계9항목 통과 뒤18단계가 열린 것을 확인했습니다. 수정 대상은 renderExplanation뿐이며17단계 AI 점검 함수와13~16단계 함수를 유지합니다.

## 요구사항과 검사

- 설명 오류는 event=null이어도 먼저 안전한 code/message·실패 이유로 표시합니다. 오류 없는 미선택은 기록 선택 안내로 구분합니다.
- 성공한 설명에만 현재 event.id의 `data-student-explanation-event`를 붙입니다. AI 참고용 요약·시각, 현재 근거ID와 실제 문장·규칙ID와 문장, 접속·세션·기기의 unknown을 각각 표시합니다.
- 근거ID 누락·중복·다른 사건 참조·원천 근거 부족, 지원하지 않는 조치, executed:true·사람 확인 불필요 주장은 설명 불가로 처리하고 요약·성공 속성을 남기지 않습니다. 없는 근거를 만들어 맞추지 않습니다.
- 지원 조치가 없어서 제안이 없는 경우와 AI가 제안하지 않은 경우를 구분합니다. 제안이 있으면 action/reason/근거ID·사람 확인 필요·미실행을 표시하며 실행 버튼과 네트워크 호출은 추가하지 않습니다.
- 호출마다 새 DOM을 반환합니다. 제공 코드의 선택 사건 세대·요청 취소·재조회 시 초기화는 변경하지 않았습니다. 개별 사건 두 개를 바꾸는 합성 검사와 새 사건에 이전 근거를 섞는 거부 검사를 통과했습니다.

13~18단계 검사45개 통과. 17단계 검사의 성공 입력은18단계 전체 계약(근거·규칙·제안·미실행)을 갖추도록 확장했으며 기존 성공/오류/대기/취소 단언은 보존했습니다. HTML 문자열은 textContent로만 표시합니다. 실제 클립보드·비밀·계정 정보는 읽지 않았습니다.
