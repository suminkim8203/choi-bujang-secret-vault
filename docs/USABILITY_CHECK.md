# 켈비 처음 사용자 검수표

상태: **미실시**. 2026-10-28 새 UI 적용과 기본 Mac 앱 검증은 끝났지만, 다른 사람이 안내만 보고 따라 하는 검수는 아직 하지 않았습니다. 새 [Mac 사용 안내](MAC_QUICKSTART.md)와 기본 앱0.1.1로 아래 검수를 진행할 수 있습니다. 이 문서는 검수 절차이며 실제 사용자 의견이나 성공 결과를 생성한 기록이 아닙니다.

## 준비

- 새 UI가 적용된 정확한 저장점과 실행 환경을 적습니다.
- 앱을 처음 쓰는 사람에게 `MAC_QUICKSTART.md`만 제공합니다. 이름·이메일·계정·비밀번호·개인 파일은 기록하지 않습니다.
- 진행자는 설명을 추가하기 전에 어디에서 막히는지 관찰합니다. 실제 수행이 없으면 미실시를 유지합니다.

## 과제와 관찰

| 과제 | 확인할 행동 | 관찰 결과 |
|---|---|---|
| 앱 켜기 | 안내만 보고 기존 프로젝트에서 켜고 주소 열기 | 미실시 |
| 내 PC 조회 | 수동 조회 버튼 찾기, 수치와 조회 시각 읽기 | 미실시 |
| 추이 비교 | 네 번 조회 후 그래프와 같은 기록표 찾기 | 미실시 |
| 상태 이해 | 미지원 항목·실측 0·보안 연결 없음을 구분해 설명하기 | 미실시 |
| 메뉴 이동 | 업무 앱·보안 기록을 찾고 보호 현황으로 돌아오기 | 미실시 |
| 기록 초기화 | 기록 지우기와 새로고침의 효과 이해하기 | 미실시 |

결과에는 실제로 관찰한 행동, 막힌 문구·버튼, 받은 도움만 적습니다. 예상 소요 시간이나 가상의 발언을 실제 관찰로 채우지 않습니다.
