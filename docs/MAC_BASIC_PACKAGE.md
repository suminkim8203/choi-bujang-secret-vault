# 켈비 기본 Mac 앱 검증 — 2026-10-28

승인한 UI를 적용한 소스를 보존하면서 별도 폴더에서 `.app`과 ZIP을 다시 만들었습니다. **로컬 Mac 기본 포장·실행 검증 완료이며 최종 과제 접수는 하지 않았습니다.**

## 산출물과 기준

- 앱: `켈비.app`, ZIP: `Kelbi-Mac-arm64-basic-0.1.1.zip`.
- 기본 wrapper 버전: `0.1.1-dev.20261028`. 제공 앱 시작 틀0.2.19와 서로 다른 버전입니다.
- ZIP: 119,012,442바이트, SHA-256 `e8c78f6dc5139dd10eb63fc9cfe2e3ac5ef87a7c6a7d928753dc2b70d6631f5c`.
- Electron45.0.0 / Forge8.0.1 / 내장 Node24.22.0. 기존에 검토한 고정 의존성을 재사용했으며 새 버전으로 올리지 않았습니다.
- 플랫폼: macOS arm64. 현재 Apple Silicon Mac에서만 실제 실행했습니다.
- 제공 앱 `src/`, `public/`, `student/`, `package.json`의45파일을 기준 해시와 대조했습니다. 이전 포장본과 달라진 제공 앱 파일은 승인한 `public/index.html`, `public/style.css` 두 개뿐입니다.
- ASAR에는 wrapper의 package.json과 src/main.mjs·lifecycle.mjs만 들어갑니다. 원본 Git·비밀 설정·의존성·과제 증빙·이전 앱 묶음은 넣지 않았습니다. 화면은 브라우저 Node 권한 없이 자체 임시 loopback 서버를 읽습니다.
- 포장은 당시 미커밋 작업을 포함한 검토 작업 트리를 기준으로 했습니다. 후속 저장점에는 동일한 앱45파일과 [포장 재현 소스](../packaging/mac-basic/README.md)를 보존합니다. 최종 소스는 이 문서가 포함된 커밋으로 식별하며, 예전 HEAD를 이번 완성본의 커밋으로 쓰지 않습니다.

이전 앱이 실행 중이어서 검증용 새 앱은 별도 TMPDIR 아래 임시 프로필로 실행했습니다. 기존 사용자 프로필과 조회 기록을 닫거나 지우지 않았습니다. 실제 실행 파일은 새 ZIP에서 푼 앱과 동일하며, 이 프로필 분리를 기본 사용자 프로필에서의 교체 실행 시험으로 확대하지 않습니다. 기존 앱을 종료하고 새 앱을 여는 방법은 실행 안내에 명시했습니다.

## 상태와 한계

새 UI는 화이트·회색 바탕과 선명한 파란 포인트, 박스 없는 상단 메뉴·버튼, 어절 줄바꿈, 회색 연결 없음으로 사용자 승인을 받았습니다. 원본 적용은 별도 스킬 거래에서 검증됐고 이번 앱도 같은 HTML/CSS를 사용합니다.

PC 상태 조회·그래프·현재 탭 기록이 로컬 제품의 완성 범위입니다. 실제 보안 엔진·계정·AI·조치 집행·Windows·Intel Mac·다른 Mac·공증 배포는 이번 시험에 포함하지 않습니다. Mac 미지원 항목을0/정상으로 표시하지 않습니다.

새 UI의 웹 실행은1280×720/390×844에서 별도 검증했습니다. 이번 기본 앱은 실제 native 창에서 확인했습니다. 다른 사람의 안내만 보고 따라 하기, 화면 낭독기와200% 확대 검수는 미실시이며 AI 검사로 대체하지 않았습니다.

원본 조회 실패·재실행 복구는 UI 적용 작업에서 실제 검증했고, 이번 기본 앱에서는 정상 조회·초기화·종료·재실행을 재확인했습니다. 시험별 근거를 서로 합쳐 공식 심판 판정으로 표시하지 않습니다.

현재 공식 제출은 정규 과제의 저장소 URL·40자리 커밋이며 포장·파일 첨부는 선택입니다. [현재 제출 경로](FINISH_SUBMISSION_ROUTE.md)를 따르고, 명시적 제출 지시 전에는 접수하지 않습니다.
