## 지원·미지원

- Mac 개발본 추가 확인: CPU·메모리·디스크·네트워크 구성 실측, Windows 두 항목 미지원 표시, 수동 조회·실패의 현재 값 제거·기록20회 상한·지우기·새로고침 초기화·키보드 초점. 새11검사와 기존62검사를 구분합니다. 같은 브라우저의 기본/예제 실행 확인이며 다른 사용자의 따라 하기·확대/화면 낭독기 검수는 미확인입니다.
- 공식0.2.19는 Windows 승인 실행 환경을 사용하는 포장 도구를 포함합니다. 현재 Mac 개발 실행을 설치형 앱 포장·서명·배포·최종 접수 완료로 바꾸어 적지 않습니다.

- 직접 확인: Mac loopback 앱, 같은 소스의62개 합성 검사, 실제 demo와 연결 없음의 표시, 수동 재조회·실패와 기존 판정/기록 분리, 새 폴더·재시작. 운영 AI·보안 집행을 직접 확인한 결과가 아닙니다.
- 공식 제공 지원 경로: Node22~24·Windows 실행 도구와 자격 저장소, 담당자가 준비한 SDP·AI·조치·OSV 연결. 현재 프로젝트에서 실제 사용·검증한 경로와 분리합니다.
- 기다림(UNV): Windows native 계정·AI 앱 승인, 실제 사용자 사건과 AI 계정 대응, 실제 모델 추론·취소 경쟁, 실제 원천 집행·효과 조회, 승인된 프로젝트의 원격 OSV 조회와 설치 메타데이터 대조.
- 미지원 행동: 학생 함수의 자동 조치·자동 재시도, 임의 인증/기기/모델 생성, 개인키·Workbench 키 복사, 확인 불가를 허용·안전·성공으로 표시.

## 인수인계

[학생 실행 설명서](STUDENT_RUNBOOK.md)에서 현재 Mac 개발본과22단계 당시 기록을 구분한 뒤 [22단계 최종 재현 기록](FINAL_REPRODUCTION.md)을 읽습니다. 22단계 제출본의 실행 소스는20단계 뒤 동일했고, 이후 Mac 개발본에는 제공 업데이트와 학생 기능이 추가됐습니다. 과거65파일 지문을 현재 개발본 지문으로 사용하지 않습니다. 공식 최종 제출SHA는 포털과 루트 README에서 추적합니다. 문서·스크린샷·과제 통과가 실제 운영 연결 인증을 대신하지 않습니다.

기존 코드·학습 DB·원격 이력·비공개 자격은 보존합니다. DB/자격의 복구는 코드 checkout만으로 처리할 수 없으며 재현 기록의 대상별 보존 계획을 따릅니다. 운영 연결 검증과 미완료 조건이 충족되기 전에는 v1.0·운영 도입 완료로 표시하지 않습니다.


22단계 실제 판정·최종 커밋 검증은 [최종 검증 기록](STAGE22_VERIFICATION.md)을 봅니다. 판정 후 기록 커밋은 앱·검사를 바꾸지 않았으며 추가 재제출하지 않습니다.
