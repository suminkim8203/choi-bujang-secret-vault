# 켈비 비UI 과제 검증 — 2026-10-27

사용자 요청에 따라 UI를 수정하지 않고 현재 기능의 새 폴더 재현과 포장 사전 점검을 진행했습니다. **중간 검증이며 최종 패키지·제출 결과가 아닙니다.**

**후속 정정:** 아래 0.2.19 포장 사전 점검 결과는 그대로지만, 현재 운영 제출은 저장소 URL·40자리 커밋 기준이며 포장을 요구하지 않습니다. 실행 환경 누락은 선택적인 Windows 설치형 작업에만 해당합니다. [현재 운영 안내·공식 R7 검증](FINISH_SUBMISSION_ROUTE.md)을 우선합니다.

## 새 폴더에서 직접 확인한 결과

공식 `planApp(source, {providedRuntime:true})`의 읽기 전용 계획에 포함된 앱 파일 77개를 새 폴더에 복사했습니다. 비공개 설정·Git·의존성·캐시를 복사하지 않았으며, 각 파일의 실제 바이트를 SHA-256으로 대조했습니다. 이 옵션을 읽기 전용 계획에 사용한 것은 승인 실행 환경의 존재나 공식 포장 성공을 의미하지 않습니다.

- 포함 앱 파일: 77개, 1,345,637바이트.
- 공식 `sourceSnapshot` 방식의 현재 파일 지문: `2620a0c6e9c6b647a6ff9c9e9a012cfc5b22599716becbcf0e3c5a6b4092b92f`.
- 소스 내용의 제공 비밀값 패턴 검사 통과. 이 검사가 모든 종류의 비밀을 완벽하게 탐지한다는 뜻은 아닙니다.
- 새 사본의 저장소 검사 9파일·73항목 통과, JavaScript/모듈 40파일 문법 검사 통과.
- 현재 개발 환경은 Mac / Node.js 24.10.0 / npm 11.6.0입니다. Windows 수업 기준 환경을 재현한 결과가 아닙니다.

서버는 자격 환경변수를 물려받지 않고, AI·보안 엔진 연결 없이 loopback의 별도 포트로 실행했습니다. 원본 앱과 DB·인증·제공 서버 코드는 바꾸지 않았습니다.

## 포장 사전 점검에서 확인한 것

공식 도구의 읽기 전용 소스 계획과 출처 검사를 사용했습니다. 압축·설치 묶음·최종 제출 자료는 만들지 않았습니다.

1. 현재 소스에는 미커밋 변경이 있어 `blocked-uncommitted`입니다. 지금의 중간 UI를 최종 제출 커밋으로 고정하지 않았습니다.
2. 현재 Mac의 공식 실행 환경 조회 결과는 `PROVIDED_RUNTIME_NOT_INSTALLED`입니다. 학원 Windows PC의 설치 여부까지 이 결과로 판단하지 않습니다.
3. `student/appearance.json`은 형식상 valid이지만 아이콘 설정은 없습니다. 공식 포장에는 허용된 아이콘 설정 또는 검증 가능한 PNG 입력이 필요합니다. 새 UI 작업에 맞춰 나중에 정합니다.
4. 제공 안내의 설치형 화면은 검증된 제공 화면을 사용합니다. 현재 웹 CSS와 최종 설치형 화면이 같은지 아직 확인하지 않았습니다.

사용자는 학원 Windows PC를 사용할 수 있다고 답했습니다. 그 PC에서의 실제 버전·승인 실행 환경·설치 결과는 아직 미확인입니다. [Windows 인수인계](WINDOWS_FINISH_HANDOFF.md)로 이어갑니다.
